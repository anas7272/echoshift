# RELAY Support Knowledge Base

## What RELAY does
RELAY is an interruptible support AI that listens to customers in real time, understands when they interrupt, preserves the latest context, and escalates to a human agent when the issue needs a person.

## Supported modes
- Text chat mode for typed support conversations
- Voice mode for spoken support conversations
- Live transcript mode with context updates
- Human handoff with preserved summary and facts

## Core workflow
1. Customer opens the support channel.
2. AI starts the conversation and asks clarifying questions.
3. Customer interrupts or corrects the issue.
4. System updates the current understanding.
5. If the user asks for human help, the AI escalates.
6. Human agent receives the full summary and context without repetition.

## When to escalate to a human
Escalate when the customer asks for a person, the issue is urgent, the account is locked, or the conversation requires policy review.

## Customer support rules
- Keep replies short and helpful.
- Preserve the latest facts and user corrections.
- Do not ask the customer to repeat the full issue after interruption.
- Summarize the issue before the handoff.

## Typical support topics
- account access issues
- login problems
- password reset requests
- service outage questions
- billing clarity questions
- support escalation requests
